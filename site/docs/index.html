Getting Started

SuperMD is a Markdown editor that reads like a finished page and edits like plain text. Formatting markers stay hidden until your cursor touches them, then reveal in place — headings, lists, tables, diagrams, all live. Open a folder and your notes know each other: wiki links with completion, backlinks, tags, and a graph — all computed from your files. Which stay plain CommonMark on disk: no database, no proprietary format, no lock-in.

Install

macOS — Download the DMG, open it, and drag SuperMD into Applications. The app is signed and notarized, so it opens without warnings. If you launch it straight from the DMG, SuperMD offers to move itself into Applications for you.

Linux — grab the .deb or the .tar.gz from the latest release.

Windows — run the installer from the latest release.

First launch

SuperMD opens with a welcome tour — and the tour itself is a real, editable document. Click things: checkboxes toggle, tables dissolve into editable text, bold markers appear under your cursor and fold away when you leave.

When you're ready to work with your own notes, press ⌘ O (Ctrl+O on Windows/Linux) or click Open Folder in the sidebar. SuperMD remembers your recent workspaces and can reopen the last one on launch.
