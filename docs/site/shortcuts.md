# Keyboard shortcuts

On Linux and Windows, read ⌘ as Ctrl.

## General

| macOS | Windows / Linux | Action |
| ----- | --------------- | ------ |
| ⌘ N | Ctrl N | New File |
| ⌘ O | Ctrl O | Open… |
| ⌘ S | Ctrl S | Save Now |
| ⌘ W | Ctrl W | Close Tab |
| ⌘ E | Ctrl E | Toggle Edit/Preview |
| ⌘ ⇧ D | Ctrl Shift D | Show Changes |
| ⌘ 1 | Ctrl 1 | Toggle Sidebar |
| ⌘ 2 | Ctrl 2 | Toggle Outline |
| ⌘ 3 | Ctrl 3 | Knowledge Panel |
| ⌃ ⌘ F | Ctrl Alt F | Focus Mode |
| ⌃ ⌘ N | Ctrl Alt N | Flux (adaptive theme) |
| ⌘ = | Ctrl = | Zoom In |
| ⌘ T | Ctrl T | Theme… |
| ⌘ P | Ctrl P | Go to File… |
| ⌘ ⇧ F | Ctrl Shift F | Search in Workspace… |
| ⌘ ⇧ ] | Ctrl Shift ] | Next Tab |
| ⌘ ⇧ [ | Ctrl Shift [ | Previous Tab |
| ⌘ ⇧ G | Ctrl Shift G | Graph View |
| ⌘ ⇧ P | Ctrl Shift P | Command Palette… |
| ⌘ / | Ctrl / | Keyboard Shortcuts |
