# Keyboard Shortcuts

Every shortcut, as shown in-app with **⌘ /** (Ctrl+/). macOS keys on the left; on Windows and Linux, ⌘ becomes Ctrl and ⌥ becomes Alt.

## General

| macOS | Windows / Linux | Action |
| ----- | --------------- | ------ |
| ⌘ N | Ctrl N | New file |
| ⌘ O | Ctrl O | Open file or folder |
| ⌘ P | Ctrl P | Go to file |
| ⌘ F | Ctrl F | Find in file |
| ⌘ E | Ctrl E | Toggle edit / preview |
| ⌘ ⇧ D | Ctrl Shift D | Show changes vs git HEAD |
| ⌘ ⇧ F | Ctrl Shift F | Search in workspace |
| ⌘ ⇧ P | Ctrl Shift P | Command palette (plugins) |
| ⌃ ⌘ F | Ctrl Alt F | Focus mode |
| ⌘ B | Ctrl B | Toggle sidebar |
| ⌘ ⇧ O | Ctrl Shift O | Toggle outline |
| ⌘ ⇧ K | Ctrl Shift K | Knowledge panel (backlinks, tags, graph) |
| ⌘ 1 | Ctrl 1 | Focus sidebar |
| ⌘ W | Ctrl W | Close tab |
| ⌃ Tab / ⌘ ⇧ ] | Ctrl Tab / Ctrl Shift ] | Next tab |
| ⌘ ⇧ [ | Ctrl Shift [ | Previous tab |
| ⌘ S | Ctrl S | Save now |
| ⌘ + / − / 0 | Ctrl + / − / 0 | Zoom image tab |
| ⌘ T | Ctrl T | Theme picker |
| ⌘ / | Ctrl / | Shortcut reference |

## Preview & read-only tabs

Applies to the ⌘E pretty preview, plugin viewer tabs (CSV, notebooks),
and the welcome tour.

| Key | Action |
| --- | ------ |
| ↑ ↓ | Scroll line by line |
| PgUp / PgDn | Scroll by a screen |
| Home / End | Jump to start / end |

## Sidebar

| Key | Action |
| --- | ------ |
| ↑ ↓ | Move selection |
| → | Expand folder |
| ← | Collapse / go to parent |
| ⏎ | Open |
| F2 | Rename |
| ⌘ ⌫ (Ctrl Backspace) | Delete to trash |
| ⌘ N / ⌘ ⇧ N | New file / folder here |
| ⌘ ⇧ M | Move to folder… |

While browsing with the arrow keys, files open in a single reusable preview tab; press ⏎ or double-click to pin a file in its own tab.
