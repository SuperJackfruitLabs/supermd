## What shipped

0.0.15 closed the link bugs that had been open since launch. The
headline is that a plain click now follows a link — see
[[Links and notes]] for what that covers.

## Decisions

- Ship the size comparison on the site (33 MB against 213 MB, both
  installed on disk). Do **not** ship the memory figure: at ~147 MB
  against a quoted 180–250 MB it is a narrow, unproven margin.
- Defer find-and-replace to 0.0.16. It is the same class of absence as
  the link bugs and a larger build than everything in 0.0.15 combined.
- Defer table row and column commands — a different theme.
